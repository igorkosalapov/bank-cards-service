# История изменений (поэтапно)

Этот файл дублирует смысловую структуру коммитов: что добавлялось и зачем.

## 1. Шаблон проекта
- Импортирован стартовый шаблон со структурой директорий и временными README_* файлами.

## 2. Сборка и запуск Spring Boot
- Подключены зависимости Spring Boot (Web/Security/Data JPA/Validation).
- Добавлены зависимости JWT, Liquibase, PostgreSQL, Swagger (springdoc).
- Создан основной класс приложения `BankCardsApplication`.

## 3. Конфигурация приложения
- Заполнен `application.yml` (datasource, Liquibase, JWT, AES).
- Добавлены типизированные настройки через `@ConfigurationProperties`.

## 4. Liquibase миграции
- Добавлены миграции схемы БД (users/cards/transfers) + индексы + внешние ключи.
- Добавлены сид-пользователи: `admin/admin` (ADMIN) и `user/user` (USER) с bcrypt-хэшами.

## 5. Доменная модель
- Сущности: `User`, `Card`, `Transfer`.
- Enum'ы: `Role`, `CardStatus`.

## 6. Репозитории и фильтрация
- JPA-репозитории для пользователей/карт/переводов.
- Спецификации для фильтрации/поиска.
- Пессимистические блокировки для безопасных переводов.

## 7. Утилиты безопасности данных
- Шифрование номера карты AES-GCM.
- Маскирование номера карты в ответах.
- Разбор срока действия карты.
- Мапперы Entity ↔ DTO.

## 8. DTO + единая обработка ошибок
- DTO запросов/ответов (auth/users/cards/transfers).
- Валидация входных данных.
- Глобальный обработчик ошибок с единым форматом ответа.

## 9. Security (JWT + роли)
- Настроен Spring Security (stateless).
- JWT-фильтр (Bearer token).
- Разграничение доступа ADMIN/USER.
- JSON ответы для 401/403.

## 10. Бизнес-логика
- Сервис пользователей (создание, список, смена роли, удаление).
- Сервис карт (CRUD, запрос блокировки, статусы, пагинация/поиск).
- Сервис переводов (только между своими, проверки статусов/баланса, транзакционность).

## 11. REST API
- Контроллеры:
  - AuthController
  - AdminUserController
  - AdminCardController
  - UserCardController
  - TransferController

## 12. Документация и dev-среда
- Docker Compose + Dockerfile.
- OpenAPI спецификация в `docs/openapi.yaml`.
- Обновлён `README.md` (запуск, переменные окружения, тестовые пользователи).

## 13. Тесты
- Юнит-тесты ключевой логики переводов.
- Тесты шифрования/дешифрования.

## 14. Очистка шаблона
- Удалены временные README_* файлы внутри `src/**`, чтобы они не попадали в итоговую сборку.
